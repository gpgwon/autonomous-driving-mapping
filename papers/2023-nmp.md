# Neural Map Prior for Autonomous Driving (NMP)

**Topic:** Past-traversal neural global map  
**Primary paper:** https://openaccess.thecvf.com/content/CVPR2023/html/Xiong_Neural_Map_Prior_for_Autonomous_Driving_CVPR_2023_paper.html

## 1. Problem being solved
Single-pass onboard perception cannot reliably reconstruct geometry obscured or absent in the current view, while repeatedly re-detecting the same location wastes historical information.

## 2. Proposed solution / core idea
Maintain a global learned neural map prior from past traversals, read relevant prior features to augment current perception, and write back new observations with learned recurrent fusion.

## 3. Architecture and technical mechanism
Current-to-prior attention allows location-specific historical features to support current BEV prediction. A GRU-like update uses recurrent state rather than treating every frame independently. Note the requirement for previous traversals or prior map construction.

## 4. Main experimental results
The original paper reports improvements on HD map prediction using a learned global prior from historical observations. Exact performance numbers are dataset/model-specific and should be read from its tables.

## 5. Limitations and validation caveats
Historical maps can become stale, noisy, or spatially misaligned; memory updates and data coverage are deployment concerns.

## 6. Research lineage / connections
Shares feature-level prior fusion with SMERF, but NMP's prior comes from sensor history while SMERF consumes externally supplied OSM road polylines.

## 7. Questions for further study (researcher interpretation)
- Which ablation isolates the proposed contribution from extra training data or model capacity?
- How does the approach behave under pose noise, missing scene elements, and geographic distribution shift?
- What would be required for bounded-latency, long-running onboard deployment?
